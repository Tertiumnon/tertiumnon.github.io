Hello world, my name is Vitalii Balabanov.

My first websites were built in Word, and I wrote HTML in Notepad++. It felt like watching the industry being born.

I still remember the sound of my dial-up modem: a long bzzz, then the handshake beeps before the connection came up.

I started with web design and moved on to a career as a software engineer. I have worked in IT since 2007, in many companies, both small and big.

My current focus is JavaScript and TypeScript projects: web apps, browser extensions, and desktop apps built with tools such as Tauri.

I like Angular because it is TypeScript first and has everything needed to build an app of any complexity. I also like the minimalism of SolidJS, a fast, React-like library. React, of course, is the industry standard.

On the backend I prefer Bun and Elysia. I am a big fan of Bun: it gives JavaScript and TypeScript developers a real performance boost.

My core belief is that everything should be fast and the code should be minimal, with less RAM and less CPU use. Code should also be clean, which is hard to keep up with at any time, and even more so in the AI era.

In my free time I work on my dream game in Unity and C#.

I use AI at work too. It is fascinating to watch how fast it changes our work. It is 2026, after all. But we still have to keep the code clean. We need to control this chaotic force. I am here to do that job. ;-)
